# HOUND - Advanced OSINT Reconnaissance Tool

## Overview
HOUND is a powerful CLI-based OSINT (Open Source Intelligence) framework designed for comprehensive reconnaissance and information gathering. Built with modularity and extensibility in mind.

## Features

### Domain Reconnaissance
- DNS resolution (A, AAAA, MX, NS, TXT records)
- WHOIS information retrieval
- SSL certificate analysis
- HTTP header enumeration
- robots.txt discovery

### IP Reconnaissance
- Reverse DNS lookup
- Shodan integration for port and service discovery
- Geolocation data

### Email Reconnaissance
- Email format validation
- MX record verification
- Domain analysis

### Username Reconnaissance
- Cross-platform social media profile checking
- GitHub, Twitter, LinkedIn, Instagram, Facebook
