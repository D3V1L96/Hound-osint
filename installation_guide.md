Installation & Setup
Prerequisites
Python 3.11+
Ollama installed with the llama3.2 model pulled.
=================================================
# Clone the repository
git clone https://github.com/D3V1L96/Hound-osint.git
cd Hound-osint

# Install dependencies
pip install -r requirements.txt

# Configure API Keys (Optional for enhanced mobile intel)
cp config/api_keys.template.json config/api_keys.json
